# HorOS Plymouth theme

`watermark.png` is the transparent HorOS logo from
`airootfs/usr/share/horos/branding/logo.png` (kept in sync by `build.sh`).

`animation-0001.png` ... `animation-0036.png` are the upstream Plymouth
spinner frames by jimmac:

- https://gitlab.freedesktop.org/plymouth/plymouth/-/blob/main/themes/spinner/animation-0008.png
- Packaged as GPL-2.0-or-later with Plymouth.
- Downloaded from a mirror because gitlab.freedesktop.org blocks automated access.

The theme uses Plymouth's built-in `two-step` module; no extra theme package
is needed.
